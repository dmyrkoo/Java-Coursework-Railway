# Курсова робота
## Варіант 8 — Рухомий склад залізничного транспорту

---

## 📌 Опис проєкту

Цей проєкт є фінальною **курсовою роботою** з дисципліни *Об’єктно-орієнтоване програмування*. 
**Варіант 8 — «Рухомий склад залізничного транспорту»**.

Метою роботи є розробка повноцінного десктопного застосунку з графічним інтерфейсом, базою даних та просунутим логуванням. Програма дозволяє формувати склад потяга, керувати вагонами, сортувати їх за рівнем оснащеності та шукати за місткістю.

---

## 🧩 Використані технології та Архітектура

Проєкт побудовано за принципом **Layered Architecture**:
- **Java JDK 17+**
- **Maven 3.6+** (збірка проєкту та управління залежностями)
- **JavaFX** (Presentation Layer — графічний інтерфейс користувача)
- **SQLite + JDBC** (Data Access Layer — реляційна база даних)
- **Logback + SLF4J + Jakarta Mail** (система логування з відправкою критичних помилок на Email)
- **JUnit 5 + Mockito + JaCoCo** (покриття бізнес-логіки юніт-тестами >90%)
- **Stream API** (Business Logic Layer — фільтрація та сортування даних)

⚙️ Особливості реалізації

    Database Seeding (Cold Start): При першому запуску програми автоматично створюється файл бази даних potiag.db, таблиці ініціалізуються та заповнюються тестовим набором даних (6 вагонів різних типів) для швидкої демонстрації роботи.

    Email Сповіщення: Усі критичні помилки, такі як некоректне введення даних користувачем або втрата з'єднання з БД, автоматично надсилаються на пошту адміністратора за допомогою SMTPAppender.

    ООП та Патерни: Використано поліморфізм, інкапсуляцію, абстрактні класи та збережено елементи патерну Command з попередніх етапів розробки.

▶️ Швидкий старт
1️⃣ Налаштування пошти (Опціонально)

Для тестування відправки помилок на Email, відкрийте файл src/main/resources/logback.xml та вставте свої дані (логін та App Password) у секцію SMTPAppender.
2️⃣ Запуск програми

Завдяки плагіну javafx-maven-plugin, програму можна запустити однією командою:
Bash

mvn clean compile javafx:run

3️⃣ Запуск тестів та перевірка покриття

Щоб запустити всі тести та згенерувати звіт JaCoCo:
Bash

mvn test

(Звіт про покриття коду буде збережено у папці target/site/jacoco/index.html)
